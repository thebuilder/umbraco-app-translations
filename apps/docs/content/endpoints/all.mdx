Returns every message, for an application that does not bundle its own text. A message an editor changed has the editor's text. Every other message has the text Umbraco read from your source.

<ParamField query="locale" type="string" required placeholder="da-DK">
  The Umbraco language code. It has to match exactly: `da` finds nothing on a site that stores `da-DK`.
</ParamField>

<ParamField query="namespace" type="string" placeholder="website">
  The [namespace](/sources#namespaces). Repeat it, as in `namespace=checkout&namespace=website`, for several namespaces, or leave it out for every namespace. Up to 20 at once.
</ParamField>

<ParamField query="format" type="string" default="next-intl">
  `next-intl` for ICU messages, or `i18next-v4` for i18next JSON v4.
</ParamField>

<ParamField header="Api-Key" type="string">
  The [delivery key](/delivery-api#access), when one is configured. A bearer token in `Authorization` works too.
</ParamField>

<ParamField header="If-None-Match" type="string">
  The ETag of a response you already have. Umbraco answers `304` until something changes.
</ParamField>

## Response

A JSON object of messages, nested the way your application's own files are. With one `namespace`, the namespace's messages sit at the top level. With several, or none, each namespace is a top-level key holding its own messages, as [one namespace, several, or all of them](/delivery-api#one-namespace-several-or-all-of-them) shows. `{}` when the locale or namespace has none.

| Status | Meaning |
| --- | --- |
| `200` | The messages. |
| `304` | Nothing changed since the ETag you sent. |
| `400` | `locale` is missing, `format` is not one of the two, the request names more than 20 namespaces, or `namespace` has a comma in it and no namespace has that name. |
| `401` | A key is configured, and the request did not send it. |
| `409` | A namespace in the response has messages in the other syntax, or two sources supply the same key. |
