Syncs one source and waits for it to finish. The endpoint is off until you configure a [secret](/syncing#with-a-secret) or an [authorization policy](/syncing#with-an-oidc-token). Send the secret below, or what your policy checks, such as an OIDC token.

<ParamField path="alias" type="string" required placeholder="website">
  The source identifier, from the source's **Advanced** settings.
</ParamField>

<ParamField header="Authorization" type="string" placeholder="Bearer replace-with-a-long-random-value">
  The deployment sync key, as a bearer token.
</ParamField>

<ParamField header="X-Oidc-Token" type="string" placeholder="eyJhbGciOiJSUzI1NiIs...">
  An OIDC token, when `DeploymentSync:AuthorizationPolicy` names a policy from [API OIDC](https://api-oidc.thebuilder.dk/). It reads this header unless you configured another.
</ParamField>

## Response

<ResponseField name="syncId" type="string" required>
  The sync's identifier, as **History** lists it.
</ResponseField>

<ResponseField name="sourceId" type="string" required>
  The source's identifier.
</ResponseField>

<ResponseField name="revision" type="string" required>
  A fingerprint of the files the sync read.
</ResponseField>

<ResponseField name="startedAt" type="string" required>
  When the sync started, as an ISO 8601 timestamp.
</ResponseField>

<ResponseField name="completedAt" type="string" required>
  When it finished.
</ResponseField>

<ResponseField name="status" type="string" required>
  How the sync ended.
</ResponseField>

<ResponseField name="addedCount" type="integer" required>
  New keys.
</ResponseField>

<ResponseField name="changedCount" type="integer" required>
  Keys whose default text changed.
</ResponseField>

<ResponseField name="missingCount" type="integer" required>
  Keys the files no longer have, deleted or kept as **No longer used**.
</ResponseField>

<ResponseField name="invalidCount" type="integer" required>
  Not `0` when the files could not be read as messages.
</ResponseField>

<ResponseField name="error" type="string">
  What went wrong, when something did.
</ResponseField>

| Status | Meaning |
| --- | --- |
| `200` | Synced. |
| `401` | The key or token is missing or wrong. |
| `403` | The token is valid, but the policy doesn't let it in. |
| `404` | No source has that identifier. |
| `409` | The source is turned off, or already syncing. |
| `502` | Umbraco could not fetch or read the translation files. |
| `503` | Neither a key nor a policy is configured, so the endpoint is off. |
